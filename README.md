# odin-recipes
The Odin Project - HTML Basics - Recipes project

## About ##
The website will consist of webpage where HTML & CSS fundamentals will be applied through the learnings from The Odin Project. Main index page will have links to a few recipes. This playground project allows me to utilise the skills learned from various fundamental sections, provided by The Odin Projects and apply it in real practice.

More importantly, I'm also applying the learning about GIT Basics whereby through regular commits in GitHub, I am able to present, and in practice, get comfortable with branching, regularly submitting updates, and reviewing my work in a structured approach and full trace of changes applied.

## The Assignments ##

### HTML Fundamentals ####
- [x] Create an `index.html` file.
- [x] Fill it out with the usual boilerplate HTML and add an `h1` heading “Odin Recipes” to the body.
- [x] Create a new directory within the `odin-recipes` directory and name it `recipes`.
- [x] Create a new HTML file within the `recipes` directory and name it after the recipe it will contain. For example `lasagna.html`. For now, just include an `h1` heading with the recipe’s name as its content.
- [x] In the `index.html` file, add a link to the recipe page you just created. The text of the link should again be the recipe name.
- [x] Add a link back to the index page on your recipe page for easier navigation. This allows users to quickly return to the home page after viewing the recipe.
- [x] Place a free image of the finished dish.
- [x] Under the image, it should have an appropriately sized “Description” heading followed by a paragraph or two describing the recipe.
- [x] Under the description, add an “Ingredients” heading followed by an unordered list of the ingredients needed for the recipe.
- [x] Finally, under the ingredients list, add a “Steps” heading followed by an ordered list of the steps needed for making the dish.
- [x] Create two more recipe pages. Make sure they have the exact same layout as your first recipe page.
- [x] Don’t forget to link to the new recipes on the index page. Also, consider putting all the links in an unordered list so they aren’t all on one line.
